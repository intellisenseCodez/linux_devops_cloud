In today’s session, we will explore how to host and deliver a **static web application** using two core AWS services:

- How object storage works in AWS

# 1. Amazon S3

## What is S3?

AWS S3 is an **object storage service** that allows you to store and retrieve any amount of data from anywhere on the internet.

S3 is designed for:

- High durability
- High availability
- Scalability
- Low-cost storage

AWS Features:
- Bucket versioning
- Event Notification
- Object Lock
- CloudTrail logging
- Encryption

It is commonly used for:

- Static website hosting
- Data lakes
- Backup and archiving
- Application assets
- Media storage


## Core S3 Concepts

### 1. Buckets

A **bucket** is a container for storing objects.

### 2. Objects

An **object** is a file stored in a bucket.


### 3. Storage Classes

S3 supports multiple storage classes depending on access pattern.

| Storage Class | Use Case |
|---|---|
| Standard | Frequently accessed data |
| Intelligent Tiering | Automatic cost optimization |
| Standard-IA | Infrequent access |
| Glacier | Archival storage |
| Glacier Deep Archive | Long-term archival |



### 4. Durability & Availability

S3 provides:

- **99.999999999% durability (11 nines)**
- Data replicated across **multiple Availability Zones**

This makes S3 highly reliable for production workloads.
